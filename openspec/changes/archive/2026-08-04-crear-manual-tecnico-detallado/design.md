# Diseño

El manual se entrega como HTML autocontenido con CSS interno para permitir su
consulta sin servidor, impresión a PDF y futura publicación estática. Mantiene
un índice enlazado, encabezado de control documental, tablas técnicas, bloques
de código y una declaración explícita de alcance Pybricks.

La fuente de verdad de cada afirmación permanece en código o documentación
existente. El documento enlaza la arquitectura C4, diferencias simulador-robot,
guías de despliegue y controles de calidad en vez de duplicar procedimientos
operativos cambiantes.
