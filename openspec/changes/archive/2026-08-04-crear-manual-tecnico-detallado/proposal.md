# Propuesta: crear manual técnico detallado

## Objetivo

Publicar un manual HTML autónomo para describir de forma técnica el Simulador
EV3 Pybricks, su instalación, arquitectura, alcance funcional, compatibilidad
Pybricks, operación, calidad y límites. Complementa, sin sustituir, la guía
rápida y el centro de ayuda.

## Alcance

- Documento HTML imprimible y navegable, conservado dentro del repositorio.
- Referencias trazables a documentación vigente, código y pruebas.
- Anexo de evidencia técnica útil para preparar un expediente de derechos de
  autor, sin pretender reemplazar requisitos o asesoría jurídica local.

## Fuera de alcance

- No se declara el registro legal realizado ni se incorporan datos personales,
  secretos, credenciales o una licencia no aprobada por el titular.
