1. Inicio rapido (5 minutos)

  1. En http://nyquist.app/simuladorlego, entra a Mundos desde el menu superior.
  2. Pulsa Validar para revisar que no existan errores.
  3. Pulsa Guardar como y elige donde guardar el JSON.
  4. Pulsa Simulacion en la barra superior para ir a la pantalla de ejecucion.
  5. Abre un script de ejemplo, ejecutalo y observa sensores, motores y telemetria.

Si quieres aprender por escenarios completos, usa el menu Escenarios en simulacion para cargar mundo y script en una sola accion.

2. Simulacion del robot (pantalla principal)

Acceso: desde el menu Simulacion dentro de la app.

Unidades: las distancias visibles en telemetria y readouts (X, Y y sensores de distancia) se muestran en centimetros (cm).

Que puedes hacer aqui

  • Crear, abrir y guardar scripts desde el menu Archivo.
  • Elegir ejemplos listos desde Ejemplos.
  • Cargar mundos desde el menu Mundos.
  • Ejecutar con controles: ejecutar, pausar, reanudar, detener y reiniciar.
  • Depurar con breakpoints haciendo clic en el margen del editor.

Apoyos didacticos del editor

  • Autocompletado Pybricks con Ctrl+Space.
  • Autoindentacion y cierre automatico de pares (), [] y llaves.
  • Vista de estado del programa y del mundo cargado.
  • Panel visual del robot: LED, pantalla, altavoz EV3 y telemetria de motores/sensores.
  • La pantalla EV3 soporta texto y dibujo monocromo 178x128 con draw_pixel, draw_line, draw_circle y draw_box.

Para ubicar el robot antes de ejecutar, usa Ubicar robot y haz clic en el canvas para fijar posicion y angulo inicial.

3. Creacion de mundos (editor)

Acceso: desde el menu Mundos dentro de la app.

Unidades: el readout de cursor y la pose inicial del robot se muestran en cm para mantener consistencia con la simulacion.

Paso a paso para construir un mundo

  1. Define el tamano en celdas y pulsa Aplicar tamano.
  2. Selecciona el tipo de asset (robot, muros, lineas, zonas o pisos).
  3. Haz clic en el canvas para colocar elementos.
  4. Selecciona elementos ya colocados para mover, rotar, duplicar o eliminar.
  5. Ajusta propiedades en el panel de propiedades (asset, posicion y rotacion).
  6. Si lo necesitas, define la pose inicial con Colocar robot.
  7. Pulsa Validar y revisa errores/advertencias en consola.
  8. Pulsa Guardar como para exportar el JSON del mundo.

El panel de propiedades te ayuda a editar con precision cuando necesitas coordenadas exactas.

4. Flujo recomendado: de mundo a simulacion

  1. Abre la seccion Mundos desde el menu superior.
  2. Crea el mundo y valida que no tenga errores.
  3. Guarda el mundo como JSON (por ejemplo prueba_lineas.json).
  4. Abre la seccion Simulacion desde el menu superior.
  5. Carga el mundo desde el menu de Mundos o con la opcion Cargar mundo desde tu equipo.
  6. Ejecuta el script Pybricks desde la pagina de simulacion.

5. Sesiones

Cada pestana crea una sesion independiente. El codigo, mundo cargado, estado de simulacion y eventos SSE no se comparten entre sesiones.

Si el servidor se reinicia, recarga la pestana para crear una sesion nueva.

6. Alcance para usuario final

Esta aplicacion ya esta desplegada por el equipo tecnico en http://nyquist.app/simuladorlego. Como usuario final no necesitas ejecutar scripts locales, abrir terminal ni configurar el servidor.

Tu flujo recomendado es: entrar a la URL publicada, navegar por Mundos y Simulacion, y trabajar todo desde la interfaz web.

7. Problemas comunes

No aparece el mundo guardado
Regresa a Simulacion desde el menu y vuelve a cargarlo desde Mundos.
La sesion expiro o desaparecio
Recarga la pestana. Las sesiones son temporales y viven en memoria.
El script no ejecuta
Revisa la consola de la pagina de simulacion; los errores del script no detienen otras sesiones.
No abre la aplicacion
Verifica conexion a internet y que la URL sea http://nyquist.app/simuladorlego.

8. Checklist de uso diario

  • Confirmar que el servidor esta activo.
  • Validar el mundo antes de simular.
  • Comprobar pose inicial del robot.
  • Ejecutar script y revisar telemetria.
  • Si algo falla: revisar consola y volver a cargar la sesion.
