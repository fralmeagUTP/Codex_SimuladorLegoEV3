Ayuda del Simulador EV3 Web

La version web separa la simulacion del robot y la creacion de mundos en dos pantallas distintas.

Simulacion Crear mundos

1. Simulacion del robot

Ruta: http://127.0.0.1:5050/

  • Usa Archivo para crear, abrir o guardar scripts.
  • Selecciona ejemplos desde el menu Ejemplos o desde el selector inferior.
  • Carga mundos guardados desde Mundos o desde el selector inferior.
  • Usa Escenarios para cargar mundo y ejemplo en una sola accion.
  • Ejecuta, pausa, reanuda, detiene o reinicia la simulacion.
  • Haz clic en el margen del editor para activar breakpoints por linea.
  • El editor conserva indentacion al presionar Enter y completa pares como () y [].
  • Usa Ctrl+Space para abrir autocompletado Pybricks contextual.
  • Usa Ubicar robot para fijar posicion inicial y angulo desde el canvas.
  • Observa canvas, telemetria, motores, sensores, LED, pantalla y altavoz EV3.

2. Creacion de mundos

Ruta: http://127.0.0.1:5050/worlds

  • Crea mundos con robot, muros, lineas, zonas y pisos.
  • Selecciona un asset y haz clic en el canvas para colocarlo.
  • Selecciona un asset colocado para mover, rotar, duplicar o eliminar.
  • Edita directamente asset, posicion y rotacion desde el panel de propiedades.
  • Define la pose inicial del robot con Colocar robot.
  • Valida y guarda el mundo como JSON.

3. Flujo recomendado

  1. Abre /worlds.
  2. Crea el mundo y valida que no tenga errores.
  3. Guarda el mundo con un nombre, por ejemplo prueba_lineas.
  4. Usa el enlace Simular mundo guardado.
  5. La simulacion abre /?world=prueba_lineas.json y carga el mundo automaticamente.
  6. Ejecuta el script Pybricks desde la pagina de simulacion.

4. Sesiones

Cada pestana crea una sesion independiente. El codigo, mundo cargado, estado de simulacion y eventos SSE no se comparten entre sesiones.

Si el servidor se reinicia, recarga la pestana para crear una sesion nueva.

5. Operacion local

Iniciar

.\scripts\start_web.cmd

Reiniciar

.\scripts\restart_web.cmd

Detener

.\scripts\stop_web.cmd

Verificar

.\scripts\smoke_web.cmd

Para ejecucion con Waitress:

.\scripts\start_web_waitress.cmd

6. Problemas comunes

No aparece el mundo guardado
Recarga la pagina de simulacion o vuelve a abrirla desde el enlace /?world=....
La sesion expiro o desaparecio
Recarga la pestana. Las sesiones son temporales y viven en memoria.
El script no ejecuta
Revisa la consola de la pagina de simulacion; los errores del script no detienen otras sesiones.
PowerShell bloquea scripts
Usa los wrappers .cmd, por ejemplo .\scripts\restart_web.cmd.
