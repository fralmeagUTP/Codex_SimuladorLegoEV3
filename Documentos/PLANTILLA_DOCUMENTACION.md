# Plantilla de documentacion del proyecto

Usar esta plantilla para una nueva guia operativa, tecnica o de evidencia.

## Metadatos

- **Estado:** Actual / Historico / Especializado.
- **Audiencia:** estudiante, docente, desarrollo, QA u operacion.
- **Version aplicable:** leer de `simulador_ev3/_version.py` o indicar `N/A`.
- **Fecha de revision:** AAAA-MM-DD.
- **Fuente de verdad:** archivo, especificacion o comando que respalda el texto.

## Objetivo y alcance

Explicar que resuelve el documento, que no cubre y los prerequisitos.

## Procedimiento o referencia

Incluir pasos numerados, rutas y comandos reproducibles. Indicar plataforma,
version de Python y variables de entorno cuando aplique. No incluir secretos.

## Verificacion

Indicar comando, resultado esperado y criterio de salida. Si se registran pruebas,
incluir fecha, entorno y si el resultado es actual o historico.

## Limitaciones y solucion de problemas

Documentar diferencias frente al robot, limites de seguridad, errores esperados y enlaces relacionados.

## Mantenimiento

Indicar que cambios funcionales obligan a revisar el documento y enlazar el cambio OpenSpec.
