# Formulario de comprensión del menú unificado

## Propósito

Validar con una persona estudiante o docente que la organización del menú se entiende sin explicación técnica previa. La sesión dura entre 8 y 12 minutos.

## Datos de la sesión

- Fecha:
- Producto evaluado: Web / Escritorio / Ambos
- Perfil: Estudiante / Docente
- Experiencia previa con BotLab: Ninguna / Básica / Frecuente
- Versión o commit probado:
- Evaluador:

## Instrucciones para la persona participante

“Explora la barra superior y realiza las tareas. No se califican tus conocimientos; queremos saber si los nombres y la organización son claros. Puedes decir en voz alta qué esperas encontrar.”

## Escala de comprensión

Pedir una valoración de 1 a 5 para cada afirmación:

| Afirmación | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|
| Los nombres de las categorías describen lo que contienen. | | | | | |
| Distingo Aprender, Prácticas guiadas y Misiones. | | | | | |
| Entiendo dónde cambiar opciones técnicas sin temor a dañar el programa. | | | | | |
| Sé dónde buscar ayuda y dónde reportar un problema técnico. | | | | | |
| Cambiar entre Web y escritorio resulta predecible. | | | | | |

## Criterio de aceptación

- Al menos 80 % de las tareas se completa sin ayuda por cada participante.
- Ninguna categoría tiene una calificación media inferior a 4/5 en comprensión.
- Toda confusión repetida se registra como ajuste pendiente de microcopia, orden o ayuda contextual.

## Decisión

- [ ] Aprobado sin cambios.
- [ ] Aprobado con ajustes menores documentados.
- [ ] Requiere rediseño o una nueva ronda de validación.
