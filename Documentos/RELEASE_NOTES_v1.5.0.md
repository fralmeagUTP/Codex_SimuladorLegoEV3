# Notas de versión 1.5.0

## Destacado

- Añade misiones evaluables locales compartidas por Web y Tkinter, con criterios
  versionados, evaluación determinista de trazas y resultados JSON/CSV sin datos
  personales.
- Refuerza la paridad de navegación: ayuda contextual, retorno del editor de
  mundos a simulación y menú de misiones equivalente.
- Incorpora comparación visual Tkinter en CI con artefactos de evidencia.
- Consolida los cambios completados en las especificaciones OpenSpec base.

## Calidad

- Suite automatizada: 712 pruebas aprobadas y 2 pruebas de escritorio omitidas
  cuando no existe una ventana Windows interactiva.
- Ruff, Mypy y validación estricta de OpenSpec aprobados.

## Compatibilidad

Se conserva la compatibilidad con los recursos, perfiles de simulación y API
Pybricks virtual de la versión 1.4.0.
